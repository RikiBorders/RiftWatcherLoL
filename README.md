# RiftWatcherLoL
League of Legends Statistics engine

Design: https://docs.google.com/document/d/1yzhuZO6NVqQyVGyzCaJOYMkEXU3-a3yOHOhM5iYEpOs/edit?tab=t.0


You can test the API endpoints using the invoker. Just run the invoker script with `python src/rift_watcher_invoker/invoker.py` and it will execute the example usage code

To run basic unit tests, just run `pytest`
